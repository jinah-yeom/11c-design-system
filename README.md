# 11c Design System

Keeper 서비스의 디자인 시스템입니다.

## Documentation

https://11c-design.vercel.app

## Packages

| Package | Description |
|---|---|
| [`tokens/`](./tokens) | Design token source files (Token Studio JSON) |
| [`styles/tokens.css`](./styles/tokens.css) | Design tokens and theme definitions (자동 생성) |
| [`components/ui/`](./components/ui) | Core UI component library |

## For Designers

Figma Token Studio에서 토큰을 관리합니다.
컴포넌트 스펙은 문서 사이트에서 확인하세요.

## For Developers

React 기반 프로젝트에서 컴포넌트와 토큰을 활용합니다.
- 토큰 값: `styles/tokens.css`
- 컴포넌트 가이드: https://11c-design.vercel.app
- 컴포넌트 코드: `components/ui/`
